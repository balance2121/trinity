🎬 영화 티어리스트 기획서

1. 기획 개요

  • 서비스명: 영화 티어리스트 (Netflix Edition)
  • 목적: 내가 본 영화를 등급(S/A/B/C)으로 나누고, 영화별 정보와 한줄 평가를 기록·관리
  • 디자인 컨셉: 넷플릭스 다크모드 스타일 (Black & Red)

2. 핵심 기능

기능 설명
영화 추가 입력 폼을 통해 새로운 영화 데이터를 등록
포스터 표시 이미지 URL을 입력받아 영화 포스터를 시각화
별점 시스템 1~5점 사이의 별점(⭐) 기록 기능
영화 정보 감독, 제작년도, 장르 등 상세 정보 포함
등급 분류 S, A, B, C 티어별 섹션 자동 배치
데이터 유지 로컬스토리지(LocalStorage)를 활용한 데이터 보존

3. 화면 구성 요소

  • Header: 서비스 타이틀 및 로고
  • Input Section: 영화 정보를 입력하는 카드 형태의 폼
  • Tier Board: S, A, B, C 등급별 가로 행(Row) 구성
  • Movie Card: 포스터, 제목, 별점, 감독, 장르, 한줄평이 포함된 카드

4. 입력 항목 상세

항목 입력 방식 비고
제목 텍스트 필수 입력
포스터 URL 텍스트(URL) 이미지 링크 주소
별점 숫자 (1~5) ⭐ 아이콘으로 변환
감독/년도/장르 텍스트/숫자 상세 정보
한줄 평가 텍스트 나만의 감상평
등급 Select 선택 S, A, B, C 중 선택

5. 개발 로드맵

  • 1단계: HTML/CSS 기본 레이아웃 및 넷플릭스 테마 적용
  • 2단계: JavaScript를 이용한 영화 추가 로직 구현
  • 3단계: 등급별 필터링 및 화면 렌더링 기능 개발
  • 4단계: 로컬스토리지 연동 및 예외 처리 (이미지 오류 등)
